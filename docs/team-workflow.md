\# CargoSphere Backend Team Workflow



\## Repository



This repository contains the backend monorepo for CargoSphere.



\## Main Rule



Do not push directly to `main`.



All work must be done using feature branches and Pull Requests.



\## Branches



```text

main    -> stable working backend code

develop -> active integration branch

feature/\* -> individual feature or service work

test/\* -> testing-related branches
